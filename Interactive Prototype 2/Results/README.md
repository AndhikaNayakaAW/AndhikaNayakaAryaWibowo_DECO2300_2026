# Week 12 results

These files are blank collection templates prepared before the mandatory studio. No new participant result or rating has been entered.

- `Session Results.csv` contains eight planned task rows for each of five planned participant slots.
- `Post-Test Ratings.csv` contains six blank rating rows per planned slot.
- `Stroke Record.csv` contains ten planned first-stroke attempts per slot.
- `Results Summary.md` is a blank post-session summary.
- Use a fresh `Testing/Participant Record` for each person. Record consent, date, device, APK, prompts, and any incomplete session.

Planned IDs are not recruited participants. Add or remove slots to match the actual session. Keep an omitted task as Not run. Use Independent, Assisted, Incomplete, Blocked, or Not run in the task result column. Prompt counts, time, and observations must come from the session. Never copy earlier 5/5 ratings into these rows.

Record file names for consented media. Keep names and contact details out of public CSV files. Record notes-only sessions honestly. Do not turn notes into an invented transcript. Replace missing measurements with an explicit missing value during analysis rather than guessing.
