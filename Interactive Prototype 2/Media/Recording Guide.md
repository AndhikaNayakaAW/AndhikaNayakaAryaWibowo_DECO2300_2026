## Optional short demonstration structure

The supplied recording is about 5 minutes 38 seconds. The task description supplied by the student did not specify a video duration. The structure below is optional if a shorter or closer screen demonstration is useful. It is not an additional requirement.

| Approximate time | Show and explain |
| --- | --- |
| 0:00 to 0:20 | Name the prototype and state the study task. Show the running classroom and both physical controllers. |
| 0:20 to 0:40 | Show the guide and navigation. Demonstrate X to the board and Y to a table. |
| 0:40 to 1:20 | Show the seated board-and-paper view. Write on fixed paper, erase a small part, and clear it with the right controller. |
| 1:20 to 2:00 | Use the whiteboard, change colour, erase, and clear. Keep the visible tool feedback in frame. |
| 2:00 to 2:40 | Record a short board action, Stop, and Play. Explain that replay stores drawing actions and timing, not audio. |
| 2:40 to 3:00 | Briefly state the IP2a-to-IP2b improvements and the current limits. |

Use Quest casting or native screen recording where available. Narration should explain what the viewer is seeing. If a controller press is not visible, describe it clearly. Do not label desktop simulation as physical headset evidence.
