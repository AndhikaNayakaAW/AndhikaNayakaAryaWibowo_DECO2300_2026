# AI Use Disclosure

This project was developed with AI-assisted support. The exact disclosure wording can be adapted to the DECO2300 assessment requirements.

AI assistance was used for:

- Unity C# scripting and code organisation;
- XR Interaction Toolkit and OpenXR configuration assistance;
- runtime whiteboard drawing, interpolation, marker, and eraser implementation;
- scene-builder implementation;
- debugging compile errors and package API mismatches;
- setup, controls, architecture, and implementation documentation.

The project remains intended to be read, explained, tested, and modified by the student. Hardware testing claims are not generated automatically: Quest behaviour still needs to be verified on the target headset.
