# Whiteboard Project Agent Rules

- This is a Unity 6.3 LTS project.
- Never change the Unity version without explicit permission.
- Never commit Library, Temp, Logs or other generated Unity caches.
- Do not convert the render pipeline.
- Preserve the XR/OpenXR configuration.
- Primary hardware target is Meta Quest.
- Controller interaction must remain functional.
- Hand interaction is secondary but supported.
- Keep custom project code under Assets/XRStudyWhiteboard.
- Do not introduce multiplayer unless explicitly requested.
- Prefer official Unity and Meta packages over third-party frameworks.
- Do not remove DesignProcess documentation.
- Do not force-push or rewrite Git history.
