# Interactive Prototype 2 working files

The [submission folder](../../Interactive%20Prototype%202/START%20HERE.pdf) contains PDF documents and the required local MP4, APK, and Unity ZIP. This working archive keeps editable documents, collection spreadsheets, JSON metadata, document builders, validation tools, source images, and the original MOV. These are preserved for revision rather than included in the submission folder.

The editable Unity project remains in [Whiteboard](../../Whiteboard). None of the Python document tools implement the VR application.

Run builders and checkers from the repository root using their paths under `Working Files/Interactive Prototype 2/Tools`. Builders create editable documents here. Export revised PDFs to the matching folders under `Interactive Prototype 2`. The delivery overview builder writes the Start Here and paper-photo PDFs directly to that folder.

The original Syifa MOV is local in this archive's Media folder. The submission Media folder keeps the 1080p MP4. Large media, APKs, and source ZIPs are excluded from Git. Submit those local files through the course's required upload method.
