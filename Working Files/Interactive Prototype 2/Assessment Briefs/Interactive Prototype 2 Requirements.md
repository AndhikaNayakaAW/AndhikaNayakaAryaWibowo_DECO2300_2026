# Interactive Prototype 2 requirements

This summary records the task description supplied by the student on 21 October 2026. Confirm the exact allocated studio and submission link in the course site.

Interactive Prototype 2b is an individual, in-person, identity-verified hurdle worth 35%. The supplied assessment window is 22 to 23 October 2026. The Week 12 studio is mandatory unless prior approval has been granted.

IP2b must iterate IP2a by improving the previous prototype, exploring another interaction, or exploring another XR modality. This project follows the improvement route using the Unity VR classroom and physical controllers.

Required testing material includes a design journal with sketches and development notes, the prototype purpose, construction decisions including scope, a testing approach with participant tasks and feedback methods, Unity source, and a video of the working prototype. The plan is due before the first studio. Materials and outcomes are due by the end of the allocated testing session.

The Evaluation 3 and Reflection brief is a separate report requirement. It allows three pages of results and one reflection page, excluding title and appendices. The prototype testing plan is a prospective document and must not be replaced by a completed evaluation report.
